# Constellation — Test Website

An interactive particle constellation that reacts to touch and mouse.
Built with plain HTML5 Canvas — no dependencies, no build step.

## Run locally

```bash
python3 server.py
```

Then open the URL printed in the terminal on any device on your local network.

## What it does

- Particles drift and connect with glowing lines when near each other
- Tap or drag to repel particles and spawn bursts of new ones
- Fully touch-friendly — works great on iPad
